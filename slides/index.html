Block 1

Python 怎麼跑起來？

電腦只看得懂機器語言，我們寫的 source code 要先翻譯

直譯 Interpreting：邊翻邊跑

.py->直譯器 一行翻一行跑->結果Ex：Python

寫完直接跑、好除錯、好跨平台　/　每次都要翻比較慢

編譯 Compilation：全部翻完再跑

.c / .cpp->編譯器 全部翻完->.exe->結果Ex：C / C++

跑得快　/　改了要重編、不好跨平台

function：把一段程式包起來重複用

def calculate_total(price):
    tax = price * 0.05
    return price + tax

answer = calculate_total(100)
print(answer)
105.0
  • 先定義 def，再呼叫
  • price：parameter 參數 (裡面)
  • 100：argument 引數 (外面傳進去)
  • return：傳出來的值
  • 沒寫 return -> 回傳 None

為什麼要用

不用重複寫、改一個地方就好、程式好讀可以分工

try - except：出錯也不要整個爆掉

try:
    n = int("Hi")

    print("Undefined")

  • 沒處理的 error -> 程式中斷 (考題叫 Unhandled exception)

Review

新手 5 大坑

1. float 不精準

0.1 + 0.2 == 0.3 是 False

2. ** 由右到左

2 ** 3 ** 2 是 512 不是 64

3. b = a 不是複製

要 a.copy() 或 a[:]

4. (1) 不是 tuple

要寫 (1,)

5. 函式裡偷改外面的變數

沒寫 global 就 += -> UnboundLocalError

小測驗：會印出什麼？

def do_the_mess(parameter):
