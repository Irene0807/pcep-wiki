# PCEP 課程介紹

來源：[raw/PCEP_course_introduction.pdf](../../raw/PCEP_course_introduction.pdf) (4 頁)

## 重點
- PCEP = Python Institute 的 Python 入門證照
- 官方大綱 4 個 Block
  - Block 1：Computer Programming and Python Fundamentals -> python、int、print、`+ - * / & =`
  - Block 2：Control Flow -> `while`、`for`
  - Block 3：Data Collections -> list、tuple、dictionary、string
  - Block 4：Functions and Exceptions -> function、return、recursion、error
- 官網：https://pythoninstitute.org/pcep
