# Lesson 4 函式與例外

來源：[raw/PCEP_lesson4_only_key_point.pdf](../../raw/PCEP_lesson4_only_key_point.pdf) (39 頁)

## 重點
- 4.1 function 先定義 (def) 再呼叫 (call)
  - 優點：不用重複寫、好改、好讀 (可以分工)
  - recursion：function 裡面呼叫自己
- 4.2 傳進去的叫引數 / 參數，傳出來的叫回傳值
  - argument (外面) vs parameter (裡面)
  - required、default、positional、keyword 參數
  - scope：local > global，函式裡要改外面的變數要寫 `global`
  - 沒寫 return -> 回傳 None
- 4.3 try - except：沒有的話程式直接爆掉、中斷
