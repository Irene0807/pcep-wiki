# Lesson 1 Python 基礎

來源：[raw/PCEP_lesson1_only_key_point.pdf](../../raw/PCEP_lesson1_only_key_point.pdf) (48 頁)

## 重點
- 1.1 基本名詞：自然語言 vs 機器語言、Python 是高階語言、CPython、Console、IDLE、Script
  - Python 名字來自 Monty Python 喜劇，不是蟒蛇
- 直譯 vs 編譯：Python 邊翻邊執行，C/C++ 全部翻完再執行
- 程式要對三關：lexis 詞彙 -> syntax 語法 -> semantics 語意
- 1.2 keywords、指令、縮排、註解 (`#`、ctrl + /)
- 1.3 型別：bool、int、float、str、None、科學記號；進位制 0b / 0o / 0x
- 變數命名規則 + PEP 8
- 1.4 運算子：數學、字串、比較、布林、位元；優先級
- float 不精準：`0.1 + 0.2` 不等於 `0.3`
- 1.5 `print()` 的 sep / end、`input()`、型別轉換 `int() float() str() bool()`
